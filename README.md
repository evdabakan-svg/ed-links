# ED Links
Стартовый интерфейс сервиса музыкальных smart links, отдельный от ED studio.

## Сейчас
- Адаптивная страница релиза.
- Кнопки популярных музыкальных площадок.
- Основа для коротких ссылок и аналитики переходов.

## Следующие этапы
1. Подключить реальные данные релизов и обложек.
2. Сделать закрытую админ-панель создания и редактирования релизов.
3. Сохранять URL площадок и считать просмотры/клики.
4. Заложить владельца для каждого релиза, чтобы добавить аккаунты артистов позднее.

## Развёртывание
Создать отдельный GitHub-репозиторий `ed-links`, загрузить файлы в корень и импортировать репозиторий в Vercel. Для этой статической версии сборка не нужна: Framework Preset — Other, Build Command — пусто, Output Directory — `.`.
Позже можно подключить поддомен через Vercel Domains и DNS у регистратора.
